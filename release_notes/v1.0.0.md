# IP Blender Tool v1.0.0 - Release Notes

Bienvenido a la versión de producción 1.0.0 de **IP Blender Tool**, la herramienta definitiva de automatización y gestión de colas de renderizado para Blender en Windows.

## Qué incluye esta versión
- **Wizard de Configuración Inicial (First-Run):** Asistente automático para la localización e integración con `blender.exe`, `ffmpeg.exe` y directorios del proyecto.
- **Múltiples Modos de Escaneo de Ingesta:**
  - *ID Legacy / Modo IP:* Integración y compatibilidad con directorios de infografía legados (e.g. `(0024)*`, estructurado con carpetas `03_BLENDER` y `06_RENDERS`).
  - *Carpeta Manual:* Escaneo completo de directorios personalizados con detección recursiva de archivos `.blend`.
  - *Archivo .blend Único:* Escaneo y renderizado directo para archivos individuales de Blender.
- **Cola de Renderizado No Bloqueante:** Threading en segundo plano para renderizar sin congelar la interfaz, control de arranque, pausa y cancelación segura del proceso de Blender (proceso árbol mediante `psutil`).
- **Post-Procesamiento Automático:** Integración con FFmpeg para compilar secuencias de animación en video MP4 y renderizado de imágenes de montaje final.
- **Notificaciones Fuera de Banda:** Notificaciones asíncronas automáticas (con miniaturas renderizadas de previsualización) hacia canales de Telegram y Discord Webhooks.
- **Diagnósticos y Utilidades Offline:** Preflight checks, generador de proyectos demo offline y empaquetador ZIP de logs redactados por seguridad.

## Cómo instalar
1. Descarga el instalador ejecutable `IP-Blender-Tool-Setup-1.0.0.exe`.
2. Ejecuta el instalador (se instalará en la ruta local de tu usuario: `%USERPROFILE%\AppData\Local\Programs\IP Blender Tool\`). No requiere permisos de administrador.
3. Abre el programa mediante el acceso directo generado en el Escritorio o Menú de Inicio.
4. Completa el asistente inicial (First-Run Wizard) configurando tus carpetas de proyectos y la ubicación de `blender.exe`.

## Cómo actualizar
- Para actualizar de una versión anterior a la v1.0.0, simplemente descarga y ejecuta el nuevo instalador.
- **Garantía de persistencia:** El instalador reemplazará los archivos ejecutables pero **NO modificará ni eliminará tu configuración, base de datos de renders ni historial de trabajos**, que se conservan intactos en la carpeta AppData del usuario.

## Dónde se guardan los datos de usuario
Los datos de configuración, logs y base de datos local persistente se almacenan de forma segura y aislada en:
`%APPDATA%\IP Blender Tool\` (C:\Users\<Usuario>\AppData\Roaming\IP Blender Tool\)
- `jobs.sqlite`: Historial de renderizado, jobs, snapshots y configuración.
- `logs/`: Registros de ejecución detallados y salidas stdout/stderr de procesos de Blender.

## Limitaciones conocidas
- **Antivirus / Windows SmartScreen:** Debido a que el instalador es nuevo y no está firmado digitalmente con un certificado EV, Windows Defender SmartScreen podría mostrar un aviso en la primera ejecución. Haz click en "Más información" -> "Ejecutar de todas formas".
- **Ruta de Blender:** Se requiere que Blender esté configurado correctamente en el asistente para poder escanear escenas y renderizar.

## Exportación de Diagnósticos
Si encuentras algún error o necesitas soporte técnico:
1. Ve al panel **Diagnósticos y Utilidades** en la parte inferior izquierda.
2. Haz click en **📦 Exportar ZIP de Diagnóstico**.
3. Guarda el archivo `.zip` generado (que contiene registros de error y configuraciones redactadas sin tokens personales) y compártelo con el soporte.
